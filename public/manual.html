1. 시작하기

접속 방법

아래 주소를 브라우저(크롬 권장)에서 열면 됩니다. 앱 설치 필요 없음.

https://gradpath-phi.vercel.app

첫 방문 안내

처음 접속하면 상단에 안내 배너가 표시됩니다. 학번과 입학연도를 입력하고 이수한 과목을 추가하면 졸업요건 달성률을 바로 확인할 수 있습니다.

학번과 입학연도 입력

1
대시보드 → 학생 정보 섹션

페이지를 열면 "학생 정보" 입력 폼이 있습니다.

2
학번 7자리 입력

예: 2220001 (숫자 7자리만 입력, 다른 형식은 오류 표시)

3
입학연도 선택 (2015~2026)

드롭다운에서 본인 입학연도를 선택하면 해당 연도의 졸업 요건이 자동으로 적용됩니다.

4
저장 버튼 클릭

저장하면 브라우저에 자동 기억됩니다. 다음에 열어도 유지됩니다.

데이터 저장 방식: 학번·이수 과목 등 졸업 관련 데이터는 내 브라우저(localStorage)에만 저장됩니다. 단, 계정(로그인)과 게시판 글·댓글은 Firebase 클라우드에 저장되어 모든 사용자가 실시간으로 공유합니다.

2. 대시보드 (/)

대시보드 시뮬레이터 로드맵 게시판 타이머

졸업 요건 전체 현황을 한눈에 볼 수 있는 메인 페이지입니다.

레벨 시스템

전체 이수율에 따라 레벨이 자동으로 부여됩니다. 다음 레벨까지 몇 학점 남았는지도 표시됩니다.

이수율레벨설명
0% ~ 24%🌱 새내기막 시작한 단계
25% ~ 49%📚 중급생과목을 쌓아가는 중
50% ~ 74%💻 고학년절반 이상 달성
75% ~ 99%🎯 졸업예정자마무리 단계
100% + 모든 영역 충족🎓 졸업가능!졸업 요건 완전 충족

달성 뱃지 (5종)

각 영역 요건을 충족하면 뱃지가 파란색으로 활성화됩니다. 미달성 뱃지는 흐리게 표시됩니다.

뱃지달성 조건
🏅 전공필수 완료전공필수(전필) 필요 학점 이상 이수 + 필수 과목 전부 이수
🏅 공통교양 완료공통교양(교필) 필요 학점 이상 이수 + 필수 과목 전부 이수
🏅 균형교양 완료균형/일반교양(교선) 필요 학점 이상 이수
🏅 전공선택 완료전공선택(전선) 필요 학점 이상 이수
🎓 졸업요건 전체 충족위 4개 모두 충족 + 총 졸업학점(120 또는 130) 달성

이수율 차트

  • 도넛 차트: 전체 이수율(%)을 원형으로 시각화
  • 막대 차트: 5개 영역별 이수 학점 vs 필요 학점 비교
  • 진행률 바: 각 영역별 달성 비율 — 100% 달성 시 ✓ 충족 표시

미충족 항목 (경고)

졸업 요건 중 아직 충족하지 못한 항목들이 목록으로 표시됩니다. 경고가 모두 사라지면 졸업 요건 충족입니다.

경고 유형의미
[전필] 이수 학점 부족전공필수 학점이 모자람 — 필수 과목 추가 이수 필요
[교필] 필수 과목 미이수공통교양 필수 과목 중 미이수 과목 있음
[선수과목] ○○ 미이수이수한 과목의 선수과목을 먼저 이수하지 않음
[학점초과] N학년 M학기해당 학기 등록 학점이 최대 허용 학점 초과 (2024년 입학: 18학점, 2023년 이전: 20학점)
졸업 가능 판정: 헤더 우측 배지가 파란색 "졸업 가능"으로 바뀌면 현재 이수 내역으로 졸업 요건이 충족된 것입니다.

이수 과목 관리

이수한 과목마다 영역을 색상으로 구분한 뱃지가 태그에 표시됩니다.

전필 전공필수   전선 전공선택   교필 공통교양   교선 균형교양   자선 자유선택

+
과목 추가 — 검색 후 클릭

하단 "과목 추가" 영역에서 과목명·코드·영역(전선, 교필 등)으로 검색할 수 있습니다. 결과에서 버튼을 클릭하면 이수 과목으로 등록됩니다.

×
과목 제거

"이수 과목" 영역에서 태그 옆 × 버튼을 클릭하면 목록에서 제거됩니다.

3. 시뮬레이터 (/simulate)

대시보드 시뮬레이터 로드맵 게시판 타이머

"다음 학기에 이 과목들을 들으면 졸업할 수 있을까?"를 미리 확인하는 기능입니다. 실제 이수 내역은 변경되지 않습니다.

사용 방법

1
과목 검색

과목명, 과목코드, 영역(전필·전선·교필 등)으로 검색합니다.

2
+ 추가 클릭

수강 예정 과목을 시뮬레이션 바구니에 추가합니다. 이미 이수한 과목은 "완료"로 표시됩니다.

3
실시간 결과 확인

우측에서 졸업 가능 여부, 변경되는 학점, 영역별 변화를 즉시 확인합니다.

4
초기화

시뮬레이션 결과를 지우려면 상단 "초기화" 버튼을 클릭합니다. 실제 이수 내역에는 영향 없습니다.

영역별 변화 바 읽는 법

  • 파란색 바 → 현재 이수 학점
  • 회색 바 → 시뮬레이션 과목 추가 후 예상 학점
  • 회색이 파란색보다 길면 시뮬레이션으로 학점이 추가된 것
  • 요건 충족 시 "요건 충족" 메시지 표시
선수과목 미충족 주의: 선수과목을 이수(또는 시뮬레이션 추가)하지 않은 과목을 추가하려 하면 "선수과목 필요: ○○○" 오류 메시지가 표시되고 추가되지 않습니다.

4. 로드맵 (/roadmap)

대시보드 시뮬레이터 로드맵 게시판 타이머

취업, 대학원, 자격증 취득 등 다양한 목표별 선배들의 로드맵을 참고할 수 있습니다.

로드맵 목록 (10개)

목표로드맵 이름
취업백엔드 개발자, 프론트엔드 개발자, 보안 전문가, 데이터 사이언티스트, 임베디드/IoT, 클라우드/DevOps, 게임 개발자
대학원AI/ML 연구자, 소프트웨어 아키텍트
자격증정보처리기사 취득

사용 방법

  • 상단 필터로 목표별 분류: 전체 / 취업 / 대학원 / 자격증
  • 카드의 "상세" 클릭 → 학년별 계획, 활동, 목표 기업 모달 확인
  • "저장" 클릭 → 로드맵 상단에 "내 계획" 배너 표시

5. 집중 타이머 (/timer)

대시보드 시뮬레이터 로드맵 게시판 타이머

뽀모도로 기법(25분 집중 + 5분 휴식)을 기반으로 한 공부 타이머입니다.

기본 조작

버튼기능
시작타이머 시작. 원형 바가 채워지며 카운트다운
일시정지타이머 멈춤. 다시 시작하면 이어서 진행
리셋현재 세션 취소, 25분 집중으로 초기화

자동 전환 & 통계

  • 25분 집중이 끝나면 자동으로 5분 휴식으로 전환
  • 집중 세션 완료 시 오늘 세션 수 +1 기록
  • 오늘 현황: 완료 세션 수 + 누적 집중 분
  • 이번 주 세션: 최근 7일 일별 세션 수 꺾은선 그래프
  • 통계는 브라우저 저장소에 날짜별로 누적 저장됩니다
뽀모도로 기법이란? 25분 집중 → 5분 휴식을 반복하는 시간 관리 방법입니다. 짧은 집중 단위로 생산성을 높이고 번아웃을 방지하는 데 효과적입니다.

6. 로그인 / 회원가입 (/login)

대시보드 시뮬레이터 로드맵 게시판 로그인 타이머

게시판에 글을 쓰거나 댓글을 달려면 계정이 필요합니다. 로그인하지 않아도 읽기는 가능합니다.

회원가입

1
상단 네비바 "로그인" 클릭 → 회원가입 탭 선택

로그인 페이지에서 "회원가입" 탭을 클릭합니다.

2
아이디(4자 이상) + 비밀번호(4자 이상) 입력

아이디는 숫자·영문·한글 모두 가능합니다. 중복 아이디는 사용할 수 없습니다.

3
가입하기 클릭 → 랜덤 닉네임 확인

가입 완료 화면에 닉네임이 표시됩니다. 형식: 형용사 + 동물 + 숫자 (예: 활발한여우327)

4
"확인 — 시작하기" 버튼 클릭

닉네임을 확인한 후 버튼을 누르면 대시보드로 이동합니다.

주의: 닉네임은 랜덤 부여되며 변경할 수 없습니다. 아이디와 비밀번호를 잊어버리면 복구가 불가능하므로 반드시 기록해두세요.

로그인 / 로그아웃

  • 로그인: 아이디 + 비밀번호 입력 후 로그인 버튼 클릭
  • 로그인 성공 시 상단 네비바에 닉네임이 표시됩니다
  • 로그아웃: 네비바 우측 "로그아웃" 버튼 클릭
  • 로그인 상태는 브라우저를 닫아도 유지됩니다 (localStorage 세션)
계정 데이터 저장 위치: 계정 정보(아이디·비밀번호·닉네임)는 Firebase 클라우드에 저장됩니다. 다른 컴퓨터에서도 같은 계정으로 로그인할 수 있습니다.

7. 선후배 게시판 (/board)

대시보드 시뮬레이터 로드맵 게시판 로그인 타이머

졸업 후 진로, 취업, 대학원, 자격증 등에 대해 선배에게 질문하고 답변을 받을 수 있는 실시간 공유 게시판입니다. 모든 사용자가 같은 게시판을 공유합니다.

카테고리

카테고리용도
진로질문졸업 후 커리어 방향, 취업/대학원 선택 등 일반적인 진로 고민
취업기업 준비, 인턴, 포트폴리오, 코딩 테스트 관련
대학원대학원 진학, 연구실, 장학금, 입시 관련
자격증정보처리기사, 네트워크관리사 등 자격증 준비
일반위 카테고리에 해당하지 않는 자유 주제

글쓰기

1
로그인 후 "글쓰기" 버튼 클릭

비로그인 상태에서는 "로그인 후 작성" 버튼이 표시됩니다.

2
카테고리 · 제목 · 내용 입력

제목은 최대 80자, 내용은 자유롭게 작성합니다.

3
"등록" 클릭

즉시 게시판에 반영되며, 다른 사용자도 실시간으로 볼 수 있습니다.

댓글 · 삭제

  • 게시글 클릭 → 상세 모달에서 댓글 달기 가능 (로그인 필요)
  • 본인이 작성한 게시글·댓글만 삭제 가능 — 삭제 전 확인 다이얼로그가 표시됩니다
  • 삭제된 게시글·댓글은 복구할 수 없습니다

검색 및 필터

  • 상단 검색창: 제목, 내용, 닉네임으로 검색
  • 카테고리 버튼: 원하는 카테고리만 필터링
실시간 동기화: 게시판 데이터는 Firebase Firestore에 저장되어 모든 기기·사용자가 실시간으로 공유합니다. 페이지를 새로고침하지 않아도 새 글이 자동으로 표시됩니다.

** 2025~2026년 요건은 2024년 기준 추정값이며, 공식 확정 시 변경될 수 있습니다.

주의: GradPath의 요건은 블루북 기준으로 입력되어 있습니다. 개인별 예외사항(편입, 복수전공, 학점 인정 등)은 반영되지 않으므로, 최종 확인은 반드시 학과 사무실 또는 계명대 포털(K-Cloud)에서 진행하세요.

9. 자주 묻는 질문

Q. 다른 컴퓨터에서 내 이수 내역이 안 보여요
데이터는 각 브라우저의 로컬 저장소에만 저장됩니다. 다른 컴퓨터에서는 다시 입력해야 합니다.
Q. 입학연도를 바꾸면 요건이 바뀌나요?
네. 입학연도 선택 후 저장하면 해당 연도의 졸업 요건이 즉시 적용되어 이수율과 경고가 다시 계산됩니다.
Q. 시뮬레이터에서 추가한 과목이 대시보드에도 반영되나요?
아닙니다. 시뮬레이터는 가상 계획만 확인하는 기능입니다. 실제 이수 내역은 대시보드에서만 수정됩니다.
Q. 채플(0학점)은 어떻게 처리하나요?
채플은 학점은 0이지만 필수 과목입니다. 대시보드 과목 추가에서 "채플 (P/F 필수)"을 검색해 추가해야 관련 경고가 사라집니다.
Q. 선수과목이 뭔가요?
특정 과목을 수강하기 위해 먼저 이수해야 하는 과목입니다. 예를 들어 "C++프로그래밍"은 "C프로그래밍"을 먼저 들어야 합니다. 시뮬레이터에서 선수과목 없이 추가하려 하면 오류가 표시됩니다.
Q. "학점초과" 경고가 뜨는데 어떻게 해야 하나요?
과목에 설정된 학년/학기 기준으로 같은 학기에 등록한 학점 합계가 최대 허용 학점(2024년: 18학점, 2023년 이전: 20학점)을 초과할 때 표시됩니다. 실제로 초과 수강 신청이 된 경우 학과 사무실에 확인하세요.
Q. 자유선택 학점을 채우기 어려워요
GradPath에는 체육활동(FR001)·봉사활동(FR002) 2개의 자선 과목만 등록되어 있습니다. 실제로는 타 학과 과목, 교양 초과 이수 학점 등이 자선으로 산입되므로, 과목을 모두 입력하기 어려운 경우 참고용으로만 활용하세요.
Q. 과목이 목록에 없어요 한계
GradPath에는 전공 68개 + 교양(교필 7개, 교선 572개) + 자선 2개 등 총 643개 과목이 등록되어 있습니다. 목록에 없는 과목(타 학과 과목 등)은 반영할 수 없습니다. 수강 계획 확정은 학과 사무실 또는 수강신청 시스템을 이용하세요.
